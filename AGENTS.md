# sidequesting.dev

Personal blog + portfolio for DrMrProfessor. Cybersecurity career focus.

## Stack
- Astro (blog template starter)
- Deployed via Cloudflare Pages, auto-builds on push to `main`
- Content in `src/content/blog/` as Markdown

## Design direction
- Cyberpunk 2077 aesthetic: near-black bg, electric yellow (#fcee0a) primary
  accent, cyan (#00f0ff) and magenta (#ff2e97) secondary
- Signature element: terminal "boot sequence" intro that resolves into the hero
- Fonts: Chakra Petch (display), Share Tech Mono (mono/utility)
- Keep it readable — bold in one place, quiet everywhere else

## Conventions
- Australian English spelling
- Don't commit secrets; this is a public repo
- Ask before force-pushing or deleting files
